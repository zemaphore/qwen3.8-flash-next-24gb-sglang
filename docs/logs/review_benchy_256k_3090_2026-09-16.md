# Review: llama-benchy depth sweep to 256K (RTX 3090)

Date: 2026-09-16 UTC

Base commit: `41d1f2b` ("Use qwen38-flash-256K as the 3090 API model name")

Decision: **REVIEW-ONLY**. This run starts and stops no server and changes no
launcher, asset or patch. It records the depth scaling of the accepted PP stack
on the RTX 3090 so the refined level already reached is attested in the repo.

## Scope

The accepted stack served the OpenAI API model ID `qwen38-flash-256K` at
`http://127.0.0.1:30001/v1` with presence placement, S184, chunk 4608, gather
block 2048, PP7 DMA staging, PP11 batched DMA, PP14 cross-layer prefetch and the
accepted PLE/KV settings (`docs/logs/pp14_cross_layer_prefetch_3090_2026-09-16.md`).
`llama-benchy` was run over a depth sweep out to the full 262,144-token context.
No A/B is attached: the purpose is to measure the depth response of the accepted
configuration, not to compare two configurations.

## Reading

* **Prefill is nearly depth-flat.** From `d8192` to the full `d262144` context,
  `pp2048` moves only from 1363.82 to 1237.51 tok/s, **-9.3% across a 32x
  increase in context**. The elastic expert cache, the lazy KV backing and the
  PP14 cold-row prefetch are holding up at the 256K end; no depth cliff appears.
* **TTFT is linear in total context.** `est_ppt` rises 1.85 s -> 193.4 s as the
  depth grows, i.e. the fixed per-chunk cost dominates and the O(prefix) QSA
  term does not bend the curve. A 256K-context prefill returns its first token in
  about 194 s.
* **Decode is flat.** `tg128` stays in 28.96-31.95 tok/s (peak 29.50-32.50) at
  every depth, so attention over the tiered INT8/INT4 KV pool does not degrade
  decode as context fills.
* The `d0` point is the cold, first-request row (it exercises the expert and PLE
  paths before they are warm) and is the low end of the sweep by construction.

Comparison to the adjacent PP14 record is not controlled and uses a different
decode length: PP14 logged `pp2048 @ d2048` at 1218.09 +/- 42.17 and
`tg256 @ d2048` at 31.21 +/- 0.67
(`docs/logs/pp14_cross_layer_prefetch_3090_2026-09-16.md:92-94`). This sweep
starts at `d8192` and is the first record of the accepted stack's depth
response; the two runs used different servers and host state.
